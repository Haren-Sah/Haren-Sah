## ⚙️ Featured Project

### 🔹 NetBox-Driven Data Center Fabric Automation

An end-to-end automation pipeline that transforms network intent into configuration and validation using NetBox as the Source of Truth.

**What it does:**
- Discovers topology automatically from NetBox
- Builds structured network inventory
- Generates Cisco & Arista BGP configurations
- Validates generated state vs intended design
- Produces automated network documentation (Markdown + diagrams)

**Architecture:**
NetBox → Python → Topology Discovery → Jinja2 → Config Generation → Validation → Documentation

**Tech Stack:** Python, NetBox API, Jinja2, JSON, Git
